# 现在到必胜算法

## **算法概述**
本算法为寻找五子棋最优策略而服务，通过以下三个部分来实现：
1. **WinStrategy** - 包含五子棋核心逻辑，可加载棋盘数据、更新玩家信息并进行威胁检测和阵法匹配，运行时会遍历当前棋盘及其镜像的四个方向，确保算法的正常实现
2. **WinningPart** - 涵盖13种黑棋的强攻阵法和8种白棋的反击阵法，每个阵法含3~5个由数组对应的棋盘状态，基于这些阵法给出建议落子位置及理由
3. **main** - 负责初始化程序并开始执行，提供阵营及json输入方式的选择，读取及处理数据，提供输出弹窗

## **运作逻辑**
```mermaid
graph TD
    classDef startend fill:#F5EBFF,stroke:#BE8FED,stroke-width:2px,color:#333
    classDef process fill:#E5F6FF,stroke:#73A6FF,stroke-width:2px,color:#333
    classDef decision fill:#FFF6CC,stroke:#FFBC52,stroke-width:2px,color:#333
    
    A([开始]):::startend --> B{是否为黑棋首步}:::decision
    B -- 是 --> C("天元落子"):::process
    B -- 否 --> D(评估最佳落子位置):::process
    D --> E(检查必胜点):::process
    E --> F{存在必胜点?}:::decision
    F -- 是 --> G(在必胜点落子):::process
    F -- 否 --> H(检查防御点):::process
    H --> I{存在必须防御点?}:::decision
    I -- 是 --> J(在防御点落子):::process
    I -- 否 --> K(评估进攻价值):::process
    K --> L{存在高价值进攻点?}:::decision
    L -- 是 --> M(在进攻点落子):::process
    L -- 否 --> N(评估威胁等级):::process
    N --> O{存在低级威胁?}:::decision
    O -- 是 --> P(在威胁点落子):::process
    O -- 否 --> Q(策略性占位):::process
    Q --> R(优先中心区域):::process
    R --> S{中心区域有空位?}:::decision
    S -- 是 --> T(占据中心区域):::process
    S -- 否 --> U(围绕已有棋子扩展):::process
    U --> V{存在扩展点?}:::decision
    V -- 是 --> W(在扩展点落子):::process
    V -- 否 --> X(随机落子):::process
    X --> Y{存在空位?}:::decision
    Y -- 是 --> Z(随机选择空位落子):::process
    Y -- 否 --> AA([平局]):::startend
    C --> AB([结束]):::startend
    G --> AB
    J --> AB
    M --> AB
    P --> AB
    T --> AB
    W --> AB
    Z --> AB
```

## **算法实现细节**  
### **数据结构**  
-**棋盘表示：** 使用`9×9`的二维数组表示棋盘，其中`0`表示空位，`1`表示黑棋，`-1`表示白棋  
-**Json格式：** 输入输出均为Json格式，方便与外部系统集成
### **关键算法**  
-**威胁检测算法：** 扫描棋盘上的每行，检测是否存在冲四、活四、活三等威胁模式  
-**阵法匹配算法：** 将当前棋盘状态与预定义阵法进行匹配，支持四向旋转和镜像对称  
### **坐标转换**  
-**数组坐标转数学坐标：** 将内部使用的数组坐标（行，列）转换为数学坐标（x, y），其中x表示列索引加1，y表示9减去行索引
